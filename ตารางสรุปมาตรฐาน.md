**1\. มาตรฐาน WCAG 2.1 (Web Accessibility)**

- **เจ้าของ / ผู้ออกแบบ:** W3C (World Wide Web Consortium)
- **ที่มา:** W3C Web Accessibility Initiative (WAI)
- **จำนวนเช็กลิสต์:** **37 ข้อ** (แบ่งตาม 6 หมวดหมู่)

| **หมวดหมู่ / หัวข้อเช็กลิสต์**           | **รายละเอียดหัวข้อที่เช็ค**      | **วิธีเช็ค / เกณฑ์ที่จะผ่าน (Pass Criteria)**                                                                                                     |
| ---------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **หมวด 1: โครงสร้าง HTML (8 ข้อ)**       |                                  |                                                                                                                                                   |
| • Document Title                         | ตรวจหาแท็ก &lt;title&gt;         | **วิธีเช็ค:** สแกน DOM โค้ดหน้าเว็บ<br><br>**เกณฑ์ผ่าน:** ต้องมีแท็ก &lt;title&gt; และมีข้อความระบุชื่อหน้าชัดเจน                                 |
| • Document Language                      | ตรวจแอตทริบิวต์ภาษา              | **วิธีเช็ค:** ตรวจสอบแท็ก &lt;html&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีแอตทริบิวต์ lang เช่น lang="th" หรือ lang="en"                                 |
| • Valid Language Code                    | ตรวจสอบรหัสภาษา                  | **วิธีเช็ค:** เทียบค่าใน lang กับมาตรฐาน BCP 47<br><br>**เกณฑ์ผ่าน:** ต้องเป็นรหัสที่มีอยู่จริง                                                   |
| • Heading Order                          | ตรวจการเรียงลำดับ &lt;h1-h6&gt;  | **วิธีเช็ค:** ไล่ระดับโครงสร้าง Header<br><br>**เกณฑ์ผ่าน:** ลำดับหัวข้อต้องไม่ข้ามกระโดด (เช่น ห้ามข้ามจาก h2 ไป h4)                             |
| • List Structure                         | ตรวจโครงสร้างแท็กรายการ          | **วิธีเช็ค:** สแกนแท็ก &lt;ul&gt;, &lt;ol&gt;, &lt;dl&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีเฉพาะแท็กลูกที่ถูกต้อง (&lt;li&gt;, &lt;dt&gt;, &lt;dd&gt;) |
| • List Items                             | ตรวจแท็ก &lt;li&gt;              | **วิธีเช็ค:** สแกนตำแหน่งแท็ก &lt;li&gt;<br><br>**เกณฑ์ผ่าน:** ต้องอยู่ภายใต้ &lt;ul&gt; หรือ &lt;ol&gt; เท่านั้น ห้ามลอยเดี่ยว                   |
| • Iframe Title                           | ตรวจแอตทริบิวต์ใน &lt;iframe&gt; | **วิธีเช็ค:** ตรวจแท็ก &lt;iframe&gt; ทั้งหมด<br><br>**เกณฑ์ผ่าน:** ต้องมีแอตทริบิวต์ title="..." อธิบายเนื้อหา                                   |
| • Table Structure                        | ตรวจโครงสร้างตาราง               | **วิธีเช็ค:** ตรวจแท็ก &lt;table&gt;<br><br>**เกณฑ์ผ่าน:** ต้องกำหนดส่วนหัว &lt;th&gt; และระบุ scope ให้ถูกต้อง                                   |
| **หมวด 2: ฟอร์มและอินพุต (5 ข้อ)**       |                                  |                                                                                                                                                   |
| • Input Labels                           | ตรวจการเชื่อม Label              | **วิธีเช็ค:** สแกนช่อง input, textarea, select<br><br>**เกณฑ์ผ่าน:** ต้องผูกกับ &lt;label&gt; หรือมี aria-label                                   |
| • Image Buttons                          | ตรวจปุ่มที่เป็นรูปภาพ            | **วิธีเช็ค:** สแกน &lt;input type="image"&gt;<br><br>**เกณฑ์ผ่าน:** ต้องใส่แอตทริบิวต์ alt                                                        |
| • Autocomplete                           | ตรวจแอตทริบิวต์เติมอัตโนมัติ     | **วิธีเช็ค:** สแกนแท็กฟอร์มกรอกข้อมูล<br><br>**เกณฑ์ผ่าน:** ใช้ค่า autocomplete ตรงตามสเปก HTML5                                                  |
| • Fieldset & Legend                      | ตรวจการจัดกลุ่มฟอร์ม             | **วิธีเช็ค:** ตรวจแท็ก &lt;fieldset&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีแท็ก &lt;legend&gt; อธิบายชื่อกลุ่มฟอร์ม                                      |
| • No Duplicate Labels                    | ตรวจ Label ซ้ำซ้อน               | **วิธีเช็ค:** สแกน Label ของอินพุตแต่ละช่อง<br><br>**เกณฑ์ผ่าน:** ช่องกรอกข้อมูล 1 ช่องต้องไม่มี Label ซ้ำซ้อน                                    |
| **หมวด 3: รูปภาพและสื่อ (5 ข้อ)**        |                                  |                                                                                                                                                   |
| • Image Alt Text                         | ตรวจข้อความอธิบายภาพ             | **วิธีเช็ค:** สแกนแท็ก &lt;img&gt; ทุกตัว<br><br>**เกณฑ์ผ่าน:** ต้องมี alt (หากเป็นภาพตกแต่งต้องใช้ alt="")                                       |
| • Image Map Alt                          | ตรวจลิงก์บนรูปภาพ                | **วิธีเช็ค:** สแกนแท็ก &lt;area&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีแอตทริบิวต์ alt อธิบายปลายทาง                                                     |
| • Object Fallback                        | ตรวจข้อความสำรองของ Object       | **วิธีเช็ค:** สแกนแท็ก &lt;object&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมี Fallback text ซ่อนไว้ภายในแท็ก                                                 |
| • Video Captions                         | ตรวจคำบรรยายวิดีโอ               | **วิธีเช็ค:** สแกนแท็ก &lt;video&gt;<br><br>**เกณฑ์ผ่าน:** ต้องใส่แท็ก &lt;track&gt; เพื่อแสดง Captions/Subtitle                                  |
| • SVG Accessible Name                    | ตรวจชื่อภาพ SVG                  | **วิธีเช็ค:** สแกนแท็ก &lt;svg&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีแท็ก &lt;title&gt; หรือ aria-label                                                 |
| **หมวด 4: การนำทางและคีย์บอร์ด (7 ข้อ)** |                                  |                                                                                                                                                   |
| • Link Name                              | ตรวจข้อความในลิงก์               | **วิธีเช็ค:** สแกนแท็ก &lt;a&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีข้อความระบุปลายทาง ห้ามเป็นลิงก์ว่างเปล่า                                            |
| • Button Name                            | ตรวจข้อความบนปุ่ม                | **วิธีเช็ค:** สแกนแท็ก &lt;button&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีข้อความบอกหน้าที่ชัดเจน                                                         |
| • Tabindex                               | ตรวจลำดับการกด Tab               | **วิธีเช็ค:** สแกนค่า tabindex ในโค้ด<br><br>**เกณฑ์ผ่าน:** ห้ามใช้ค่า tabindex > 0                                                               |
| • Unique IDs                             | ตรวจสอบ ID ซ้ำ                   | **วิธีเช็ค:** สแกน id ที่ใช้ร่วมกับ ARIA/Label<br><br>**เกณฑ์ผ่าน:** ห้ามมี ID ซ้ำกันในหน้าเดียวกัน                                               |
| • Skip Link / Bypass                     | ตรวจปุ่มข้ามเมนู                 | **วิธีเช็ค:** ตรวจองค์ประกอบแรกๆ ของ DOM<br><br>**เกณฑ์ผ่าน:** มีกลไก "Skip to main content" ให้ข้ามแถบนำทางได้                                   |
| • Hidden Focusable                       | ตรวจสอบปุ่มที่ถูกซ่อน            | **วิธีเช็ค:** สแกน element ที่ติด display:none หรือ aria-hidden="true"<br><br>**เกณฑ์ผ่าน:** ต้องไม่มีปุ่ม/ลิงก์ที่รับโฟกัสซ่อนอยู่ข้างใน         |
| • Scrollable Region                      | ตรวจกล่องเลื่อน Scroll           | **วิธีเช็ค:** สแกนพื้นที่ที่มี Scrollbar<br><br>**เกณฑ์ผ่าน:** ต้องใส่ tabindex="0" เพื่อให้ใช้คีย์บอร์ดเลื่อนได้                                 |
| **หมวด 5: การแสดงผลและสี (4 ข้อ)**       |                                  |                                                                                                                                                   |
| • Color Contrast                         | ตรวจความเปรียบต่างสี             | **วิธีเช็ค:** คำนวณค่าสีข้อความกับพื้นหลัง<br><br>**เกณฑ์ผ่าน:** อัตราส่วนอย่างน้อย (ตัวอักษรใหญ่ )                                               |
| • Viewport Zoom                          | ตรวจการล็อกการซูม                | **วิธีเช็ค:** สแกน &lt;meta name="viewport"&gt;<br><br>**เกณฑ์ผ่าน:** ห้ามมี user-scalable=no หรือ maximum-scale=1                                |
| • Orientation Lock                       | ตรวจการล็อกทิศทางจอ              | **วิธีเช็ค:** สแกน CSS Media Query<br><br>**เกณฑ์ผ่าน:** ต้องไม่ล็อกหน้าจอให้อยู่เฉพาะแนวตั้งหรือนอน                                              |
| • Text Spacing                           | ตรวจระยะห่างตัวอักษร             | **วิธีเช็ค:** ตรวจโค้ด CSS สไตล์<br><br>**เกณฑ์ผ่าน:** ต้องไม่บล็อกการปรับ letter-spacing / word-spacing                                          |
| **หมวด 6: กฎระเบียบ ARIA (8 ข้อ)**       |                                  |                                                                                                                                                   |
| • Valid ARIA Roles                       | ตรวจสอบค่า Role                  | **วิธีเช็ค:** สแกนค่าใน role="..."<br><br>**เกณฑ์ผ่าน:** ต้องสะกดถูกต้องและมีอยู่จริงในมาตรฐาน W3C                                                |
| • Valid ARIA Attributes                  | ตรวจสอบชื่อแอตทริบิวต์           | **วิธีเช็ค:** สแกนแอตทริบิวต์ aria-\*<br><br>**เกณฑ์ผ่าน:** ต้องสะกดถูกต้องตามสเปก W3C                                                            |
| • Valid ARIA Values                      | ตรวจสอบค่าภายใน ARIA             | **วิธีเช็ค:** สแกน Type Data ใน aria-\*<br><br>**เกณฑ์ผ่าน:** ใส่ค่าถูกประเภทข้อมูล (เช่น true/false)                                             |
| • Required Attributes                    | ตรวจแอตทริบิวต์บังคับ            | **วิธีเช็ค:** ตรวจความสัมพันธ์ของ Role<br><br>**เกณฑ์ผ่าน:** ต้องใส่แอตทริบิวต์คู่กันครบถ้วน (เช่น role="combobox" คู่กับ aria-expanded)          |
| • Required Parent                        | ตรวจแท็กแม่ของ ARIA              | **วิธีเช็ค:** ตรวจลำดับชั้นแท็ก<br><br>**เกณฑ์ผ่าน:** แท็กลูกต้องอยู่ใต้แท็กแม่ที่กำหนด (เช่น role="listitem" อยู่ใต้ role="list")                |
| • Required Children                      | ตรวจแท็กลูกของ ARIA              | **วิธีเช็ค:** ตรวจลำดับชั้นแท็ก<br><br>**เกณฑ์ผ่าน:** แท็กแม่ต้องครอบแท็กลูกที่กำหนด (เช่น role="menu" มี role="menuitem")                        |
| • Body aria-hidden                       | ตรวจการซ่อนหน้าเว็บ              | **วิธีเช็ค:** สแกนแท็ก &lt;body&gt;<br><br>**เกณฑ์ผ่าน:** ห้ามใส่ aria-hidden="true" ในแท็ก &lt;body&gt; เด็ดขาด                                  |
| • Dialog Name                            | ตรวจชื่อ Pop-up                  | **วิธีเช็ค:** สแกน role="dialog"<br><br>**เกณฑ์ผ่าน:** ต้องมี aria-label หรือ aria-labelledby ระบุชื่อ                                            |

**2\. มาตรฐาน Core Web Vitals & SEO (Google Lighthouse)**

- **เจ้าของ / ผู้ออกแบบ:** Google
- **ที่มา:** Google Web Vitals & Search Central Framework
- **จำนวนเช็กลิสต์:** **9 ข้อ** (แบ่งเป็น Performance 3 ข้อ และ SEO 6 ข้อ)

| **หมวดหมู่ / หัวข้อเช็กลิสต์**             | **รายละเอียดหัวข้อที่เช็ค**                  | **วิธีเช็ค / เกณฑ์ที่จะผ่าน (Pass Criteria)**                                                                                                           |
| ------------------------------------------ | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ด้าน Performance (3 ข้อ)**               |                                              |                                                                                                                                                         |
| • LCP (Largest Contentful Paint)           | ความเร็วการโหลดองค์ประกอบหลัก                | **วิธีเช็ค:** วัดเวลาการโหลดภาพ/ข้อความที่ใหญ่ที่สุดใน viewport<br><br>**เกณฑ์ผ่าน:** โหลดเสร็จภายใน วินาที                                             |
| • INP / TBT (Interaction / Blocking Time)  | ความไวในการตอบสนองคำสั่ง                     | **วิธีเช็ค:** วัดความหน่วงตอบสนองเมื่อผู้ใช้คลิก/พิมพ์ หรือวัด Total Blocking Time<br><br>**เกณฑ์ผ่าน:** ความหน่วงไม่เกิน มิลลิวินาที                   |
| • CLS (Cumulative Layout Shift)            | ความนิ่งของการแสดงผลหน้าเว็บ                 | **วิธีเช็ค:** คำนวณสัดส่วนการขยับ/กระโดดของเนื้อหาขณะโหลด<br><br>**เกณฑ์ผ่าน:** คะแนนความขยับเปลี่ยนตำแหน่งไม่เกิน                                      |
| **ด้าน SEO (6 ข้อ)**                       |                                              |                                                                                                                                                         |
| • Meta Data (Title & Description)          | ตรวจข้อมูลอธิบายหน้าเว็บ                     | **วิธีเช็ค:** สแกนแท็ก &lt;title&gt; และ &lt;meta name="description"&gt;<br><br>**เกณฑ์ผ่าน:** ต้องมีครบถ้วนและมีข้อความอธิบายเนื้อหา                   |
| • Crawling & Indexing                      | ตรวจการอนุญาตให้ Search Engine จัดเก็บข้อมูล | **วิธีเช็ค:** ตรวจแท็ก &lt;meta name="robots"&gt;, ไฟล์ robots.txt และ HTTP Status Code<br><br>**เกณฑ์ผ่าน:** ห้ามติด noindex และส่งค่า HTTP Status 200 |
| • Link Crawlability                        | ตรวจความสมบูรณ์ของลิงก์                      | **วิธีเช็ค:** สแกนแอตทริบิวต์ href ในแท็ก &lt;a&gt; ทุกตัว<br><br>**เกณฑ์ผ่าน:** ต้องมี URL ที่ใช้งานได้จริง เพื่อให้บอทไต่ต่อได้                       |
| • Canonical URL                            | ป้องกันปัญหาเนื้อหาซ้ำซ้อน                   | **วิธีเช็ค:** สแกนแท็ก &lt;link rel="canonical"&gt;<br><br>**เกณฑ์ผ่าน:** ต้องระบุ URL ต้นฉบับไว้อย่างถูกต้อง                                           |
| • Mobile-Friendly (Tap Targets & Viewport) | การรองรับผู้ใช้บนมือถือ                      | **วิธีเช็ค:** วัดขนาดปุ่มกด (อย่างน้อย 48x48px) และตรวจแท็ก Viewport<br><br>**เกณฑ์ผ่าน:** ปุ่มห่างกันพอดี จิ้มง่าย หน้าจอย่อขยายอัตโนมัติ              |
| • Structured Data (Schema.org)             | ตรวจโค้ดข้อมูลอัจฉริยะ                       | **วิธีเช็ค:** สแกนโครงสร้าง JSON-LD หรือ Microdata<br><br>**เกณฑ์ผ่าน:** เขียนรูปแบบ Schema ถูกต้อง ไม่มีไวยากรณ์ผิดพลาด                                |

**3\. มาตรฐานความมั่นคงปลอดภัยเว็บไซต์ สกมช. (NCSA Thailand)**

- **เจ้าของ / ผู้ออกแบบ:** สำนักงานคณะกรรมการการรักษาความมั่นคงปลอดภัยไซเบอร์แห่งชาติ (สกมช.)
- **ที่มา:** ประกาศคณะกรรมการการรักษาความมั่นคงปลอดภัยไซเบอร์แห่งชาติ (ข้อ ๖.๑.๑, ๖.๒.๒, ๖.๒.๗, ๖.๒.๘)

| **หมวด 1: Security Headers (4 ข้อ)**    |                                   |                                                                                                                                                                  |
| • Enforcement HTTPS                     | บังคับเชื่อมต่อแบบปลอดภัย         | **วิธีเช็ค:** ส่ง Request ผ่าน HTTP<br><br>**เกณฑ์ผ่าน:** ต้องถูก Redirect ไปยัง HTTPS (Port 443) อัตโนมัติ                                                      |
| • HSTS (Strict Transport Security)      | บังคับใช้ HTTPS บนเบราว์เซอร์     | **วิธีเช็ค:** ตรวจ Response Header Strict-Transport-Security<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ส่งออกมาจากเซิร์ฟเวอร์                                       |
| • Anti-Clickjacking                     | ป้องกันการครอบหน้าเว็บ            | **วิธีเช็ค:** ตรวจ Response Header X-Frame-Options หรือ Content-Security-Policy<br><br>**เกณฑ์ผ่าน:** มีการตั้งค่า DENY หรือ SAMEORIGIN                          |
| • Server Information Disclosure         | ซ่อนข้อมูลซอฟต์แวร์เซิร์ฟเวอร์    | **วิธีเช็ค:** ตรวจ Response Header Server และ X-Powered-By<br><br>**เกณฑ์ผ่าน:** ต้องซ่อนเวอร์ชัน หรือไม่พ่นชื่อระบบออกมาระบุชัดเจน                              |
| **หมวด 2: SSL/TLS Certificate (2 ข้อ)** |                                   |                                                                                                                                                                  |
| • TLS Version                           | ตรวจเวอร์ชันโปรโตคอลเข้ารหัส      | **วิธีเช็ค:** สแกนการจับมือ (Handshake) ของ SSL/TLS<br><br>**เกณฑ์ผ่าน:** ต้องรองรับ TLS 1.2 หรือ TLS 1.3 ขึ้นไปเท่านั้น (ปิด TLS 1.0/1.1)                       |
| • Cipher Suite Strength                 | ตรวจชุดรหัสเข้ารหัส               | **วิธีเช็ค:** ตรวจสอบอัลกอริทึมที่เซิร์ฟเวอร์ยินยอมใช้งาน<br><br>**เกณฑ์ผ่าน:** ใช้ชุดรหัสแข็งแกร่ง (เช่น AES, ChaCha20) และยกเลิก RC4/DES                       |
| **หมวด 3: ช่องโหว่บนหน้าเว็บ (2 ข้อ)**  |                                   |                                                                                                                                                                  |
| • XSS & SQL Injection                   | ตรวจการยิงสคริปต์อันตรายผ่านฟอร์ม | **วิธีเช็ค:** ยิง payload จำลองเข้าช่อง Input/Search box<br><br>**เกณฑ์ผ่าน:** ระบบต้องทำการ Sanitize/Escape ข้อความ และไม่รันโค้ดอันตราย                        |
| • Cookie Security Flags                 | ตรวจสอบความปลอดภัยของ Cookie      | **วิธีเช็ค:** ตรวจคุณสมบัติของ Session Cookie<br><br>**เกณฑ์ผ่าน:** ต้องติดธง Secure, HttpOnly และ SameSite ครบถ้วน                                              |
| **หมวด 4: เทคโนโลยี & CMS (3 ข้อ)**     |                                   |                                                                                                                                                                  |
| • Software Fingerprinting               | ตรวจสอบการระบุเวอร์ชันระบบ        | **วิธีเช็ค:** สแกนโค้ด Frontend หาเวอร์ชันของ CMS/Framework (เช่น WordPress/PHP)<br><br>**เกณฑ์ผ่าน:** ซ่อนตัวเลขเวอร์ชันเพื่อไม่ให้ผู้ประสงค์ร้ายนำไปหาช่องโหว่ |
| • Known CVE Vulnerabilities             | ตรวจสอบประวัติช่องโหว่ซอฟต์แวร์   | **วิธีเช็ค:** นำชื่อและเวอร์ชันที่สแกนพบ ไปค้นในฐานข้อมูล CVE สากล<br><br>**เกณฑ์ผ่าน:** ต้องไม่มีช่องโหว่ระดับ High/Critical ที่ยังไม่ได้อัปเดต                 |
| • Exposed Admin/Login URLs              | ตรวจหน้าล็อกอินมาตรฐาน            | **วิธีเช็ค:** สแกนเส้นทาง URL มาตรฐาน (เช่น /wp-login.php, /administrator)<br><br>**เกณฑ์ผ่าน:** เปลี่ยนเส้นทางใหม่ หรือจำกัดการเข้าถึงเฉพาะ IP อนุญาต           |

**  
4\. มาตรฐาน OWASP Top 10 Web Vulnerabilities**

- **เจ้าของ / ผู้ออกแบบ:** OWASP Foundation (Open Worldwide Application Security Project)

**ที่มา:** OWASP HTTP Security Headers

- **จำนวนเช็กลิสต์:** **10 ข้อ**

| **ชื่อ Security Header**                                      | **รายละเอียดและการป้องกันภัยคุกคาม**                                                                                                                                                                                                                                                                                              | **วิธีเช็ค / เกณฑ์ที่จะผ่าน (Pass Criteria)**                                                                                                                                                                  |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1\. Content-Security-Policy (CSP)**                         | **รายละเอียด:** ระบุทรัพยากรที่อนุญาตให้หน้าเว็บโหลดมาใช้งาน<br><br>**ป้องกัน:** การโจมตี XSS (Cross-Site Scripting) และ Data Injection                                                                                                                                                                                           | **วิธีเช็ค:** สแกนหา Header Content-Security-Policy<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และมีการระบุ Policy ที่รัดกุม (เช่น default-src 'self') ไม่เปิดกว้างเกินไป                                         |
| **2\. Strict-Transport-Security (HSTS)**                      | **รายละเอียด:** บังคับให้เบราว์เซอร์เชื่อมต่อผ่าน HTTPS เสมอ<br><br>**ป้องกัน:** Protocol Downgrade Attack และ SSL Stripping                                                                                                                                                                                                      | **วิธีเช็ค:** สแกนหา Header Strict-Transport-Security<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และกำหนดอายุการใช้งาน (max-age) ที่ชัดเจน เช่น max-age=31536000                                                  |
| **3\. X-Frame-Options**                                       | **รายละเอียด:** ป้องกันหน้าเว็บถูกดึงไปซ้อนใน iframe ของเว็บอื่น<br><br>**ป้องกัน:** การโจมตีแบบ Clickjacking                                                                                                                                                                                                                     | **วิธีเช็ค:** สแกนหา Header X-Frame-Options<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าเป็น DENY (ห้ามซ้อนเด็ดขาด) หรือ SAMEORIGIN (ซ้อนได้เฉพาะเว็บตัวเอง)                                             |
| **4\. X-Content-Type-Options**                                | **รายละเอียด:** ห้ามเบราว์เซอร์เดาหรือเปลี่ยนประเภทไฟล์เอง<br><br>**ป้องกัน:** MIME-sniffing ที่อาจแฝงสคริปต์อันตรายมากับไฟล์รูปหรือไฟล์อื่นๆ                                                                                                                                                                                     | **วิธีเช็ค:** สแกนหา Header X-Content-Type-Options<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าเป็น nosniff เท่านั้น                                                                                     |
| **5\. Referrer-Policy**                                       | **รายละเอียด:** ควบคุมการแนบข้อมูล URL ต้นทางเวลาคลิกลิงก์ออกไปเว็บอื่น<br><br>**ป้องกัน:** ข้อมูลลับหรือพารามิเตอร์ส่วนตัวใน URL รั่วไหล                                                                                                                                                                                         | **วิธีเช็ค:** สแกนหา Header Referrer-Policy<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าปลอดภัย เช่น strict-origin-when-cross-origin, no-referrer, หรือ same-origin                                      |
| **6\. Permissions-Policy**<br><br>_(เดิมชื่อ Feature-Policy)_ | **รายละเอียด:** จำกัดการเข้าถึงฟีเจอร์ระดับฮาร์ดแวร์ของเบราว์เซอร์<br><br>**ป้องกัน:** เว็บแอบเปิดใช้งาน กล้อง, ไมค์, ตำแหน่งที่ตั้ง (Geolocation) โดยไม่ได้รับอนุญาต                                                                                                                                                             | **วิธีเช็ค:** สแกนหา Header Permissions-Policy<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าปิดกั้นฟีเจอร์ที่ไม่จำเป็น เช่น geolocation=(), camera=(), microphone=()                                      |
| **7\. Cross-Origin-Opener-Policy (COOP)**                     | **รายละเอียด:** แยกระบบประมวลผลของหน้าเว็บออกจากเว็บอื่นที่เปิดมันขึ้นมา<br><br>**ป้องกัน:** XS-Leaks และการดึงข้อมูลผ่าน window.opener                                                                                                                                                                                           | **วิธีเช็ค:** สแกนหา Header Cross-Origin-Opener-Policy<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าเป็น same-origin                                                                                      |
| **8\. Cross-Origin-Embedder-Policy (COEP)**                   | **รายละเอียด:** บล็อกการดึงทรัพยากรข้ามโดเมนที่ไม่ได้รับการอนุญาตอย่างชัดแจ้ง<br><br>**ป้องกัน:** การแอบฝังทรัพยากรจากแหล่งที่ไม่น่าเชื่อถือ                                                                                                                                                                                      | **วิธีเช็ค:** สแกนหา Header Cross-Origin-Embedder-Policy<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าเป็น require-corp                                                                                   |
| **9\. Cross-Origin-Resource-Policy (CORP)**                   | **รายละเอียด:** จำกัดว่าเว็บไซต์ไหนบ้างที่มีสิทธิ์ดึงทรัพยากรของเราไปใช้<br><br>**ป้องกัน:** การรั่วไหลของข้อมูลข้ามโดเมนและ Side-channel Attack                                                                                                                                                                                  | **วิธีเช็ค:** สแกนหา Header Cross-Origin-Resource-Policy<br><br>**เกณฑ์ผ่าน:** ต้องมี Header นี้ และตั้งค่าเป็น same-origin หรือ same-site                                                                     |
| **10\. Cache-Control**                                        | **รายละเอียด:** ควบคุมกลไกการจดจำข้อมูล (Cache) ของเบราว์เซอร์และ Proxy<br><br>**ป้องกัน:** ข้อมูลสำคัญ/ข้อมูลส่วนตัว ค้างอยู่ในแคชสาธารณะ                                                                                                                                                                                        | **วิธีเช็ค:** สแกนหา Header Cache-Control (โดยเฉพาะในหน้าที่มีข้อมูลสำคัญหรือหน้าหลังล็อกอิน)<br><br>**เกณฑ์ผ่าน:** ควรตั้งค่าเป็น no-store, no-cache, must-revalidate เพื่อสั่งไม่ให้ระบบบันทึกข้อมูลหน้านั้น |
| **11\. Set-Cookie Attributes**                                | **รายละเอียด:** ค่าคุณสมบัติเสริมในส่วนหัวของ HTTP response ที่เซิร์ฟเวอร์ใช้กำหนดขอบเขต อายุการใช้งาน และความปลอดภัยของคุกกี้ที่ส่งมาจัดเก็บยังเว็บเบราว์เซอร์<br><br>**ป้องกัน:** บังคับให้เบราว์เซอร์ส่งคุกกี้เฉพาะผ่านการเชื่อมต่อ HTTPS เท่านั้น, ป้องกันไม่ให้สคริปต์ฝั่งไคลเอนต์เข้าถึงข้อมูลคุกกี้ลับ และจำกัดเวลาหมดอายุ | **วิธีเช็ค:** สแกนหา Header Set-Cookie (หรือเช็คผ่าน F12 แท็บ Application Cookies)<br><br>**เกณฑ์ผ่าน:** คุกกี้สำคัญต้องมีแอตทริบิวต์ Secure, HttpOnly, SameSite และกำหนดอายุ (Expires/Max-Age) อย่างชัดเจน    |
